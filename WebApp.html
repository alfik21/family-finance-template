Panduan Awal — 3 Langkah

Baru pertama kali membuka aplikasi? Ikuti urutan ini sampai data Anda tersambung.

  1. 1Salin spreadsheet Master ke Drive Anda (menu File > Make a copy), lalu jalankan menu Setup Awal di spreadsheet.
  2. 2Otorisasi & deploy Web App: Ekstensi > Apps Script > Deploy > New deployment (Execute as: User accessing), lalu buka URL-nya di HP.
  3. 3Pasang pintasan: Chrome/Safari > Add to Home Screen, dan daftarkan email pasangan di sheet CONFIG (tab Pengaturan > Akun).
