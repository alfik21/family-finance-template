## Cara Memakai

1. **Panduan Pengujian (1)** — baca dulu; berisi 26 skenario uji fungsional, klasifikasi tingkat keparahan bug, dan syarat rilis komersial.
2. **Checklist (2)** — buka `02_PRODUCT_TESTING_CHECKLIST.xlsx` di Google Sheets (`File` > `Open` > `Upload`), lalu isi kolom hasil uji riil.
3. **User Guide (3)** — ekspor ke PDF, sertakan dalam surel konfirmasi atau paket unduhan pembeli.
4. **Lisensi (4)** — ekspor ke PDF, sertakan di paket serah terima (Lynk.id / Mayar / Gumroad).

Seluruh berkas `.docx` dapat dibuka langsung di Microsoft Word, WPS Office, atau diunggah ke Google Drive untuk dibuka di Google Docs.
